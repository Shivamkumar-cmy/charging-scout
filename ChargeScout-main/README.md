# ChargeScout
# ChargeScout 🚗⚡

# ChargeScout is a static web application focused on promoting electric vehicle awareness and helping users locate nearby EV charging stations. The project highlights sustainability, EV knowledge, and location-based charging support through a clean and user-friendly interface.

🌍 Project Overview

# ChargeScout envisions a future where electric vehicles are convenient, accessible, and widely adopted. The platform provides:

Informational content about EVs and charging infrastructure

A location-based charging station view

A modern, responsive UI built using HTML, CSS, and JavaScript

🛠️ Technologies Used

HTML5 – Structure and content

CSS3 – Styling and layout

JavaScript – Interactivity and logic

Google Maps API – Location and map integration

GSAP (GreenSock) – Smooth animations

✨ Features

🚘 Home Page – Introduction and mission overview

📘 About Page – Vision and purpose of # ChargeScout

📚 Knowledge Page – Information on EV charging infrastructure

📍 Location Page – Displays nearby EV charging stations using Google Maps

🎨 Smooth Animations – Powered by GSAP

🔑 Google Maps API Setup

This project uses Google Maps API.
To make location features work:

Get an API key from Google Cloud Console

Replace YOUR_GOOGLE_API_KEY in index.html with your actual key

<script src="https://maps.googleapis.com/maps/api/js?key=YOUR_GOOGLE_API_KEY&libraries=places"></script>

🚀 How to Run the Project

Download or clone the repository

Open index.html in any modern web browser

Ensure you are connected to the internet (Google Maps requires it)
